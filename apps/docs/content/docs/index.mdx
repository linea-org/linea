Linea is a platform for building and operating agentic systems that combine
workflows, models, tools, and integrations. These docs
explain how the system fits together and how to change it safely.

<Callout type="warn" title="Early-stage project">
  Linea is pre-1.0 and under active development. Treat current code and public
  protocol definitions as authoritative when a planning document disagrees.
</Callout>

## Documentation contract

| Information                           | Source of truth                   | Documentation role               |
| ------------------------------------- | --------------------------------- | -------------------------------- |
| Public request and response shapes    | `packages/protocol`               | Explain concepts and usage       |
| Runtime behavior and node definitions | `packages/runtime`                | Explain execution and invariants |
| Persistent data                       | `packages/db`                     | Explain ownership and lifecycle  |
| Hard-to-reverse decisions             | `docs/adr`                        | Preserve context and trade-offs  |
| Contributor rules                     | `AGENTS.md` and `CONTRIBUTING.md` | Define how changes are made      |

The documentation site is versioned in the same repository. A change to a
contract or architectural boundary should update its documentation in the same
pull request.
