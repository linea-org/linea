# platform-api

NestJS backend for Linea. See the repo root [CONTRIBUTING.md](../../CONTRIBUTING.md)
for environment setup and the full variable reference — this app reads
its config from the single `.env` at the repo root, not a local one.

## Commands

- `pnpm --filter @linea/platform-api dev` — start in watch mode
- `pnpm --filter @linea/platform-api build` — production build
- `pnpm --filter @linea/platform-api test` — unit tests
- `pnpm --filter @linea/platform-api lint` / `typecheck` — same checks CI runs
