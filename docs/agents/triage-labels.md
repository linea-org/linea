# Triage labels

| Skill role        | Label                 | Meaning                                  |
| ----------------- | --------------------- | ---------------------------------------- |
| `needs-triage`    | `triage:needs-review` | Maintainer evaluation required           |
| `needs-info`      | `triage:needs-info`   | Waiting for missing information          |
| `ready-for-agent` | `triage:ready`        | Fully specified for agent implementation |
| `ready-for-human` | `triage:manual`       | Requires a person to handle the work     |
| `wontfix`         | `triage:wont-fix`     | Reviewed and declined                    |
