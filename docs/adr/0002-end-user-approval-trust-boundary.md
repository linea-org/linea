# Require independently verified end-user participation for external approvals

Linea will authorize an external-subject Decision from an End-User Session established through client-side OIDC Authorization Code with PKCE and bound to a client-held proof key using standard DPoP, not from a bearer credential minted for or visible to the Operator backend. Sessions are revocable in Linea and expire absolutely after 15 minutes; identity-provider logout prevents future exchange but need not revoke a current session before that bound. This prevents a compromised Operator backend from approving an existing request by copying a Linea token while explicitly continuing to trust the Operator's separately operated identity provider; protection from malicious Operator-controlled frontend code would require a future Linea-hosted or user-presence surface.
