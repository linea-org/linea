# Scope Agent diagnostics to admins and source retention

For the first Agent milestone, creating, viewing, and running Agent Replay and Regression requires a signed-in workspace admin or owner and authorization within the source Environment; workspace API keys do not grant diagnostic fixture access. End Users retain their own execution and approval views. This deliberately favors a narrow initial access boundary over extending the existing broadly accessible Regression interfaces to sensitive provider recordings.

A Regression Fixture expires after the source Environment's configured content-retention window, measured from when the fixture is saved. Case copies preserve the original fixture expiry and source attribution rather than extending retention or granting access across Environments. Ordinary source-trace deletion leaves the fixture available until expiry, while subject erasure or explicit deletion of the recorded content removes affected fixtures and derived diagnostic content, including copies. Missing, expired, or erased recordings produce an unavailable diagnostic result without live fallback. These are accepted target policies, not claims about current implementation.
