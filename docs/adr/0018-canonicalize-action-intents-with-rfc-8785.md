# Canonicalize Action Intents with RFC 8785

Action Consent authorizes a SHA-256 digest, encoded as base64url, of an RFC 8785 JSON Canonicalization Scheme envelope containing an envelope version, an immutable Connector Operation revision, the Connection, connector and operation identifiers, target, normalized parameters, and provider preconditions. The envelope version identifies the canonicalization and digest format; the operation revision changes whenever normalization, defaults, preconditions, or the action's meaning changes, and a pending intent must execute under its recorded revision or fail closed. Operation schemas accept only I-JSON-compatible values and normalize timestamps and binary data as strings; display text, unrelated timestamps, lifecycle state, and idempotency keys remain outside the digest, while Linea stores the canonical envelope and verifies its digest again before execution.
